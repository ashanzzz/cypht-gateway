MCP 接入

MCP 默认只读。stdio 使用本地环境变量中的 PAT；Streamable HTTP 调用方应在每个请求发送自己的 Authorization: Bearer <PAT>。写工具需要显式启动 --allow-write，并仍受 PAT scopes 与邮箱白名单限制。

stdio
CYPHT_GATEWAY_URL=http://127.0.0.1:8080 CYPHT_GATEWAY_TOKEN=cypht_pat_... cypht-mcp --transport stdio
Streamable HTTP
cypht-mcp --transport http --bind 127.0.0.1:8790 --url http://127.0.0.1:18080
endpoint: http://127.0.0.1:8790/mcp
